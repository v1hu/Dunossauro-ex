# 🐍 Exercícios de Python — Dunossauro

Repositório criado para armazenar, organizar e documentar minhas resoluções dos exercícios práticos disponíveis no [Exercícios de Python](https://exercicios.dunossauro.com/), plataforma desenvolvida para praticar e aprimorar os conhecimentos na linguagem Python.

## 🎯 Objetivo do Projeto

Consolidar os fundamentos da programação, desenvolver o raciocínio lógico e aprimorar a escrita de código Python por meio de exercícios práticos, utilizando boas práticas de programação e resolução de problemas.

## 📚 Conteúdo dos Estudos

Os exercícios estão organizados por áreas de conhecimento, abrangendo desde os fundamentos da programação até conceitos mais avançados da linguagem Python, conforme meu progresso nos estudos.

### 🧠 Fundamentos da Programação
- **Estrutura Sequencial:** variáveis, tipos primitivos, entrada e saída de dados e operadores.
- **Estrutura de Decisão:** condições e tomadas de decisão com `if`, `elif` e `else`.
- **Estrutura de Repetição:** laços de repetição com `for` e `while`.

### 🗂️ Manipulação de Dados
- **Strings:** manipulação e processamento de textos.
- **Listas:** armazenamento, organização e manipulação de coleções de dados.
- **Outras estruturas de dados:** tuplas, dicionários e conjuntos, conforme o avanço nos estudos.

### ⚙️ Conceitos e Recursos da Linguagem
- **Funções:** criação de funções, parâmetros e retorno de valores.
- **Manipulação de Arquivos:** leitura, escrita e processamento de arquivos.
- **Classes:** introdução à programação orientada a objetos.

### 🚀 Prática e Desenvolvimento
- **Resolução de Problemas:** aplicação dos conceitos aprendidos em desafios práticos.
- **Projetos:** desenvolvimento de pequenos projetos para consolidar os conhecimentos adquiridos.
- **Exercícios com Dados:** prática de conceitos relacionados à organização e ao processamento de dados.

*Os conteúdos serão explorados e atualizados progressivamente, conforme minha evolução nos estudos e os exercícios disponíveis na plataforma.*

## 🛠️ Tecnologias Utilizadas

- Python 3
- Visual Studio Code (VS Code)
- Git e GitHub para controle de versão

## 🚀 Como Executar os Exercícios

1. Acesse a pasta do exercício desejado.
2. Execute o arquivo Python pelo terminal:

   ```bash
   python nome_do_arquivo.py
   ```
